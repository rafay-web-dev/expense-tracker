# 💰 Expense Tracker

A simple and modern expense tracker built with Python and Flask.

## 🚀 Features

- Add expenses
- Track expense amounts
- Automatically calculate total expenses
- Delete expenses
- Clean and responsive interface
- Built with Python and Flask

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Jinja2
